# MY PART — لوحة تحكم React

## تشغيل المشروع

```sh
npm install
npm run dev
```

## تجهيز نسخة الإنتاج

```sh
npm run build
npm run preview
```

- `src/main.jsx`: شاشة لوحة التحكم.
- `src/Orders.jsx`: جدول الطلبات وأشكاله الأربعة حسب اختيار الدروب داون.
- `src/style.css`: تنسيق الواجهة العربية واتجاه RTL والتجاوب.
- `public/`: الخط والأيقونة.

البيانات تجريبية في الواجهة ولا ترتبط بخادم. الشعار وصور المنتجات بدائل تقريبية من المرجع.

## صفحات التعريفات

`src/Definitions.jsx` و`src/definitions.css` يحتويان صفحات السكشن التعريفي والسياسات وبنرات الأقسام والإعلانات والشريط الإعلاني. الإضافة والحذف والرفع والحفظ تعمل في ذاكرة المعاينة الحالية فقط؛ تتصفّر البيانات مع إعادة تحميل الصفحة. لا يوجد ربط بقاعدة بيانات أو تخزين دائم.

## طلبات التسعير

`src/Pricing.jsx` و`src/pricing.css`: قائمة طلبات التسعير والبحث والتصفية والتحديد وتصدير CSV قابل للفتح في Excel، وتفاصيل الطلب وإضافة المنتجات وتسعير القطع بجودات متعددة. جميع إجراءات الإرسال وإضافة المنتج محاكاة في المعاينة؛ لا يتم إرسال رسالة أو إنشاء سجل في خادم. البيانات والأسعار مؤقتة وتُصفّر مع إعادة تحميل الصفحة.

## الإشعارات والكوبونات والسلات المتروكة

`src/AdminPages.jsx` و`src/admin-pages.css` يحتويان صفحات الإشعارات والكوبونات مع الإضافة والتعديل والتفعيل، والسلات المتروكة وتفاصيل السلة. البيانات مؤقتة للمعاينة فقط. إرسال رسائل استرداد السلات محاكاة ولا يرسل رسائل فعلية.

## إدارة التصنيفات

كل كارت في التصنيفات الرئيسية يفتح إدارة القسم الخاص به. `CategoryManager.jsx` لإدارة شركات السيارات والموديلات وتصنيفات القطع، وماركات الزيوت وأنواعها ولزوجتها، وماركات الإطارات والمقاسات والتصنيع، وشجرة تصنيفات الخدمات، والإكسسوارات والتوافق والتركيب. `CategoryAnalytics.jsx` لتبويب إحصائيات قطع الغيار. جميع التعديلات بيانات معاينة مؤقتة غير مرتبطة بخادم، والصور غير المقدمة بدائل مؤقتة.

## الموظفون والصلاحيات

`src/Employees.jsx` و`src/employees.css` يحتويان قائمة الموظفين ونموذج الإضافة وصفحة صلاحيات كل موظف للقراءة والكتابة والحذف، وصلاحيات فرعية للتصنيفات والعملاء. إعدادات الصلاحيات للمعاينة فقط ولا تطبق تحكم وصول على الخادم.

## العملاء

`src/Customers.jsx` و`src/customers.css`: إدارة العملاء والتفاصيل والإضافة والتعديل والبحث، ورصيد المعاينة ونسبة الكاش باك، والمركبات والطلبات والتسعيرات والسلة والعناوين. تعديل الرصيد والحظر والتنبيه محاكاة مؤقتة ولا يحدث معاملات أو إرسالًا فعليًا.

## تذاكر المساعدة

`src/Support.jsx` و`src/support.css`: قائمة التذاكر والبحث والتصفية والحالة والتعيين والمحادثة والملاحظات الداخلية والإجراءات السريعة، وإدارة أنواع المشكلات. الرسائل والتعيين والإغلاق محاكاة مؤقتة في المعاينة ولا يتم إرسال رسائل فعلية. المرفقات بيانات تجريبية لأن ملفاتها الأصلية لم تُقدّم.

## تسجيل الدخول وOTP

`src/Login.jsx` يحتوي على صفحة البريد وكلمة المرور ثم صفحة OTP.
`src/auth-api.js` يرسل POST إلى:

- https://car-parts-backend.vercel.app/api/admin/login: `{email,password}`
- https://car-parts-backend.vercel.app/api/admin/login/verify: `{challengeId,code}`

يُقرأ challengeId من المستوى الأعلى أو data. لا تُفتح لوحة التحكم إلا بعد نجاح verify. يدعم التوكن داخل token أو accessToken أو data، أو تأكيد success/authenticated. يحتفظ بجلسة التحقق والتوكن في الذاكرة فقط، دون حفظ كلمة المرور. عند إعادة تحميل الصفحة يجب تسجيل الدخول من جديد. تسجيل الخروج يمسح جلسة الواجهة؛ لم يُقدّم endpoint لإنهاء جلسة الخادم.

يستخدم fetch مع credentials: include لدعم ملفات تعريف الارتباط. يجب السماح بنطاق الموقع في CORS وAccess-Control-Allow-Credentials: true عند استخدام الكوكيز. اختُبر مسار الدخول وOTP باستجابات محاكاة؛ تعذر اختبار الخادم الحقيقي من بيئة التنفيذ بسبب قيود الشبكة. ما زالت بقية عمليات إدارة البيانات معاينة محلية وليست مرتبطة بواجهات الخادم.

إعادة إرسال OTP: POST /api/admin/login/resend مع {challengeId}. تُحدّث بيانات التحدي والصلاحية والانتظار والمحاولات من استجابة الخادم. عند غياب وقت الانتظار يستخدم زر الإرسال مهلة واجهة احتياطية مدتها 60 ثانية، ويظل الخادم مسؤولًا عن التحقق والحدود.
